# 디자인 스타일 가이드 — 피부 케어 (app_final2)

React Native(Expo) 앱의 시각 언어를 코드 기준으로 정리한 문서입니다.
토큰의 원본은 [src/theme.ts](src/theme.ts)(앱 공용)와 [src/folders/theme.js](src/folders/theme.js)(모니터링 화면 전용)입니다.

## 1. 디자인 방향

| 키워드 | 설명 |
|---|---|
| 밝고 부드러운 헬스케어 | 연한 블루그레이 배경 위에 흰 카드를 띄우고, 라임 그린을 유일한 브랜드 포인트로 사용 |
| 카드 중심 | 모든 정보 단위는 둥근 흰 카드 한 장. 구분은 선(1px)과 옅은 그림자로만 한다 |
| 색 = 의미 | 색은 장식이 아니라 상태(좋음/주의/나쁨)를 전달할 때만 강하게 쓴다 |
| 라이트 모드 고정 | `userInterfaceStyle: "light"` — 다크 모드 없음 |
| 한국어 UI | 짧은 문장, 해요체("~해요"), 안내 문구는 작고 회색으로 |

### 2-2. 상태 색 — 두 개의 축을 섞지 않는다

**(A) 3단계 중증도 `sev1~3`** — 진단 확신도 등에 사용

| 토큰 | 값 | 의미 |
|---|---|---|
| `sev1` | `#5FC36A` | 경증 |
| `sev2` | `#F2B33C` | 중등증 |
| `sev3` | `#EB5757` | 중증 |

**(B) 4단계 지표 `LEVEL_COLORS`** — 피부 종합 상태 · 가려움 안정도 · 수면 점수 · 세부 증상 공통

| 단계 | 값 | 지표 이름 (종합/가려움/수면) | 세부 증상 이름 |
|---|---|---|---|
| 1 (가장 좋음) | `sev0` `#5B8DEF` 파랑 | 좋음 | 없음 |
| 2 | `sevCaution` `#FFD966` 옅은 노랑 | 주의 | 미미함 |
| 3 | `warn` `#F0924B` 주황 | 나쁨 | 두드러짐 |
| 4 (가장 나쁨) | `sev3` `#EB5757` 빨강 | 매우 나쁨 | 뚜렷함 |

- 두 축은 **의미가 다르므로 서로의 색을 빌려 쓰지 않는다.** (B)의 노랑이 `sev2`보다 옅은 이유는 바로 옆 단계인 주황과 구분하기 위해서다.
- 모든 지표는 **0~100점, 높을수록 좋음**으로 통일해서 보여준다(`DISPLAY_SCALE`: 원값을 100에서 역산).
- **등급 불가** 자리는 채도 없는 회색 `NO_GRADE_COLOR #AEB6C0`. 근거 없는 판정을 색으로 지어내지 않는다.

### 2-3. 차트 시리즈 색 (`CHART_SERIES`)

| 지표 | 값 | 비고 |
|---|---|---|
| 피부 종합 상태 | `#E36657` 코럴 | |
| 가려움 안정도 | `#0F9488` 청록 | |
| 수면 점수 | `#1E3A8A` 남색 | |

세 지표 모두 같은 0~100 축(눈금 25/50/75/100)의 **꺾은선**이고, 모양이 아닌 **색으로만** 구분한다. 홈 요약 칸의 원형 아이콘 배지도 같은 색을 써서 그래프와 눈으로 연결된다.

## 3. 타이포그래피

커스텀 폰트 없이 **시스템 폰트**를 사용하고, 위계는 굵기와 크기로 만든다.

| 역할 | 크기 | 굵기 | 색 |
|---|---|---|---|
| 큰 지표 숫자 | 21 | 800 | ink |
| 화면 헤드라인 | 18 | 700 | ink |
| 카드 제목 | 16~16.5 | 800 | ink |
| 버튼 라벨 | 16 | 800 | `#16320A` |
| 본문/행 라벨 | 14~15 | 700~800 | ink |
| 보조 설명 | 12~13 | 400~600 | sub |
| 안내·캡션 | 11~11.5 | 600 | sub |
| 탭 라벨 | 10.5 | 600 | 활성 greenMuted / 비활성 navInactive |

- 굵기는 **800(제목·수치) / 700(라벨) / 600(캡션)** 세 단계가 주력이다. 400~500의 얇은 글씨는 거의 쓰지 않는다.
- 보조 텍스트는 `lineHeight` 17~19로 여유 있게 잡는다.
- 제목 중 강조할 말(부위·질환명)은 크기를 키우지 않고 **`greenMuted` 색만 바꾼다.**
- 값 자리(숫자 ↔ 질환명)는 높이를 고정한 슬롯(`statValueSlot`)에 넣어 값이 바뀌어도 레이아웃이 흔들리지 않게 한다.

## 4. 레이아웃·간격

- **화면 좌우 패딩 20**, 상단 12, 하단 24 (스크롤 콘텐츠 기준).
- 카드 내부 패딩 **16** (넓은 카드는 18~24), 카드 사이 간격은 8~12.
- 자주 쓰는 `gap`: 6 / 8 / 10 / 12. 4의 배수에 가깝게 맞춘다.
- 목록 행은 `paddingVertical 15` + 아래쪽 `1px line` 구분선(마지막 행 제외).
- 상단 안전영역만 `SafeAreaView(edges=['top'])`로 처리하고, 하단은 탭바가 `insets.bottom`을 직접 더한다.
- 같은 종류의 카드는 **치수까지 동일**하게 맞춘다. (예: 홈과 촬영 탭의 "피부 바로 스캔" 카드는 글이 한쪽에서만 접히지 않도록 폭까지 같다.)

## 5. 모서리·그림자

| 요소 | 반경 |
|---|---|
| 일반 카드 (`cardDecoration`) | **20** |
| 모니터링 카드 (`monitoringCard`) | **18** |
| 주 버튼 | 16 |
| 카드 안 작은 박스(StatBox 등) | 14 |
| 입력·빈 상태 박스 | 12 |
| 단계 배지 | 9 |
| 원형 아이콘 버튼 | 반지름 = 지름/2 (42 → 21) |

카드 그림자 (Flutter 원본 `BoxShadow 0x0F1E283C, blur 18, offset (0,4)`를 그대로 옮김):

- iOS: `shadowColor #1E283C`, `opacity 0.06`, `radius 18`, `offset (0, 4)`
- Android: `elevation 3`

그림자는 **카드 한 겹에만** 쓰고, 카드 안 요소는 그림자 대신 면색(`#F6F8FA`)이나 1px 선으로 구분한다.

## 6. 핵심 컴포넌트

### 카드
`cardDecoration()` — 흰 배경 + 둥근 모서리 + 옅은 그림자. 거의 모든 화면의 기본 단위.

### 주 버튼 (Primary CTA)
- 배경 `greenTop`, 반경 16, 세로 패딩 15, 라벨 16/800 `#16320A`, 가로 전체 폭.
- 비활성: 배경 `#E7E9EC` + 라벨 `sub`.

### 원형 아이콘 버튼
- 지름 42, 배경 `greenTop`, 아이콘 22 `#16320A`. (예: 피부 바로 스캔 카드)

### SectionHeader
- 섹션 제목(16~18/800) + 오른쪽에 **작은 원형 `chevron-right` 버튼**(아이콘 18, `#333333`). "더 보러 가기"의 표준 표현.

### 체크박스 행 (`RoutineRowContent`)
- 왼쪽 둥근 체크박스: 완료 `greenTop` 채움 / 미완료 투명 + `#DADDE2` 테두리.
- **체크(했다)와 열기(하러 간다)를 영역으로 분리**한다 — 체크박스는 왼쪽 네모, 이동은 이름 영역. 한 곳에 묶으면 오조작이 난다.
- 완료 시 목록에서 사라지지 않고 **줄긋기 + 서서히 흐려짐**(`FadingCareRow`).

### 단계 배지 / MetricCard / ScaleBar
- 읽는 순서는 **무엇을 → 지금 어느 단계인지 → 얼마나**.
- 제목 옆에 단계 배지(반경 9, 흰 글자 13/800, 배경 = 단계 색)를 크게 달고, 아래 `ScaleBar`는 4단계 색 구간으로 나눠 현재 칸을 강조한다. 숫자는 참고값이라 작게 붙인다.
- 같은 `MetricCard`를 **촬영 결과 화면과 경과 관찰 상세 화면이 공유**해 생김새가 어긋나지 않게 한다.

### StatBox (홈 요약)
- 배경 `#F6F8FA`, 반경 14, 3칸 `flex:1` + `gap 8`. 위에서부터 원형 아이콘 배지(32, 시리즈 색) → 라벨 → 큰 값 → 단계 배지.

### 하단 탭바 (`BottomNav`)
- 흰 배경, 위쪽 1px `#EEEEEE`. 5개 탭: 홈 · 피부 촬영 · 기록 · 루틴 · 내 정보.
- 아이콘 24 + 라벨 10.5/600. 활성: 아이콘 `greenTop`, 라벨 `greenMuted`. 비활성: `navInactive`.

### 빈 상태
- 카드 안에 회색 아이콘(26) + 13px `sub` 문구 두 줄, 세로 패딩 24~28, 가운데 정렬. 다음 행동을 안내하는 문장("첫 촬영을 남기면 여기에 상태가 쌓여요")으로 쓴다.

## 7. 아이콘·이미지

- 기본 아이콘은 **`MaterialIcons`**(`@expo/vector-icons`) 한 종류로 통일. 크기 18/22/24/26.
- 지표 전용 아이콘은 PNG(`skin_icon`, `itch_icon`, `sleep_icon` + 흰색 버전)를 컬러 원 위에 17px로 올려 사용.
- 앱 아이콘/스플래시 배경은 `#EDF0F4`, 이미지는 `contain`.
- 신체 부위 선택은 2D 윤곽선 · 3D 메시 · 히트맵 뷰(`Body2DView`, `Body3DView`, `BodyHeatmapView`)로 표현.

## 8. 인터랙션·톤

- 카드 전체가 `Pressable` — 누를 수 있는 카드는 오른쪽에 `chevron-right`(20, `sub`)를 단다.
- 눌러서 이동하는 곳이 있으면 **화면마다 같은 모양**으로 통일한다(별도 알약 버튼을 따로 두지 않는다).
- 저장 여부·한계처럼 사용자가 미리 알아야 할 말은 행동 **직전**에 캡션으로 붙인다. ("촬영한 사진은 저장되지 않아요")
- 헤더 없음(`headerShown: false`), 화면 전환은 네이티브 스택 + 하단 탭.
